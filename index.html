4) Análisis y mejoras propuestas (ingeniería)

    
    
      
  • Centralización obligatoria: todos los coordinadores trabajan sobre un mismo calendario global con validaciones en tiempo real.
    • 
      
  • Modelo paramétrico: turnos, bloques, tipos de aula, categorías y disponibilidad docente deben ser catálogos administrables.
    • 
      
  • Reglas anti-colisión: impedir solapes por docente, aula, carrera, bloque y categoría (si no es compartida).
    • 
      
  • Clases compartidas: una asignación puede cubrir múltiples carreras sin duplicar docente ni aula.
    • 
      
  • Pipeline recomendado: configuración → recursos → asignaturas → carga académica → simulación → aprobación.
    • 
      
  • Preparado para backend Node.js: el módulo BackendAPI encapsula persistencia (hoy localStorage, mañana endpoints REST sin reescribir la UI).
